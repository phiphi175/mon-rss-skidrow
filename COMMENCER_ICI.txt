MON RSS — VERSION COMPLÈTE 1.1 (MINIATURES + 5 MINUTES)
=======================================================

BONNE NOUVELLE : CE ZIP CONTIENT TOUT LE CODE DU SITE ET DU RSS !
Il contient le programme, les pages web, les styles, le système
GitHub Actions, les dépendances et les tests.

SI TON SITE EST DÉJÀ EN LIGNE (phiphi175/mon-rss-skidrow)
------------------------------------------------------
1. Fais d'abord une copie de sécurité des deux fichiers de ton dépôt :
      docs/items.json     (historique des publications)
      docs/feed.xml       (flux RSS actuel)
2. Décompresse ce ZIP sur ton PC.
3. Dans le dépôt GitHub, ouvre Code > Add file > Upload files.
4. Envoie le CONTENU du dossier « mon-rss-skidrow-complet-v1.1 » :
   le fichier generer.py, README.md, requirements.txt et les dossiers
   docs, .github, tests, examples, etc.
   Conserve les chemins des sous-dossiers. Le fichier indispensable est
   .github/workflows/actualisation.yml (dossier caché sous Windows).
5. Clique sur Commit changes.
6. Va dans Actions > Actualisation du RSS et du site > Run workflow.
   Il sera ensuite programmé automatiquement toutes les 5 minutes.
7. Ouvre :
   https://phiphi175.github.io/mon-rss-skidrow/
   https://phiphi175.github.io/mon-rss-skidrow/feed.xml

IMPORTANT : ce ZIP ne contient VOLONTAIREMENT PAS docs/items.json
ni docs/feed.xml pour ne PAS écraser ton historique. Ce sont des
fichiers générés automatiquement au premier lancement du programme.
Conserve les deux fichiers actuels déjà présents sur ton dépôt.

SI TU CRÉES UN NOUVEAU DÉPÔT
---------------------------
Les étapes sont identiques. Dans Settings > Pages, choisis GitHub Actions
comme Source, puis lance une fois le workflow depuis l'onglet Actions.
Le programme créera automatiquement docs/items.json et docs/feed.xml.

CE QUI CHANGE
-------------
• Images miniatures sur le site + dans le flux RSS, si accessibles.
• Programmation GitHub Actions : toutes les 5 minutes (approximative).
• Conservations des anciens articles et images déjà enregistrés.
• Pour ménager la source : 4 pages d'articles au maximum par lancement,
  nouvelles tentatives d'images manquantes après 24 heures.

REMARQUES
---------
Certaines images peuvent ne pas s'afficher à cause des protections du
site d'origine ou du blocage d'affichage depuis d'autres domaines.
Le robot ne contourne pas les protections ni les erreurs HTTP 403.
La coche verte de GitHub confirme une exécution sans erreur, pas la
présence effective de nouvelles publications ou de nouvelles images.
GitHub peut retarder ou omettre des lancements programmés.

Lis README.md pour le guide détaillé et le dépannage.
