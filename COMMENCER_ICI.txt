MON FIL — INSTALLATION FACILE (5 ÉTAPES)
======================================

Ce ZIP contient un petit site web personnel et un flux RSS indépendant.
Il regroupe les TITRES, DATES (si disponibles) et LIENS des nouvelles
publications publiques de SkidrowReloaded. Il ne recopie ni les articles
complets, ni les fichiers, ni les liens de téléchargement.

1) Crée un compte gratuit sur https://github.com si nécessaire.

2) Sur GitHub, crée un dépôt PUBLIC nommé : mon-rss-skidrow
   (bouton + > New repository > Create repository).

3) Décompresse ce ZIP sur ton ordinateur, puis envoie TOUS les fichiers
   et dossiers qui sont à l'intérieur de « mon-rss-skidrow » dans le dépôt.
   Sur GitHub : Add file > Upload files > Commit changes.
   IMPORTANT : conserve le dossier caché .github et son sous-dossier
   workflows avec le fichier actualisation.yml.

4) Dans ton dépôt, va à Settings > Pages et sélectionne « GitHub Actions »
   dans Build and deployment > Source.

5) Va dans Actions > « Actualisation du RSS et du site » > Run workflow.
   Choisis main et relance avec Run workflow. Quand le déploiement
   est terminé, ouvre ton site puis copie le lien RSS.

SI TON PSEUDO GITHUB EST « exemple » :
Site : https://exemple.github.io/mon-rss-skidrow/
RSS  : https://exemple.github.io/mon-rss-skidrow/feed.xml

Remplace « exemple » par ton véritable identifiant GitHub.

La récupération s'exécute ensuite environ une fois par heure, sans
laisser ton ordinateur allumé. GitHub peut retarder ou suspendre les
actualisations.

ATTENTION : si SkidrowReloaded bloque les requêtes automatiques, le
flux peut rester vide ou conserver les anciennes publications.
Le programme ne contourne pas les protections, et le fonctionnement
à distance n'est pas garanti. Lis le fichier README.md pour l'aide
complète et le dépannage.
